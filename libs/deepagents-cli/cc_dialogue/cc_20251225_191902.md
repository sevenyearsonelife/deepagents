### 问题 2
用户：prompt-toolkit工具有什么功能？

助手：**prompt_toolkit** 是一个强大的 Python 库，用于构建交互式命令行界面。它是许多知名工具（如 IPython、ptpython、mycli）的基础。

**核心功能**：

| 功能类别 | 说明 |
|---------|------|
| **输入处理** | 多行编辑、历史记录、自动补全 |
| **视觉呈现** | 语法高亮、进度条、底部工具栏 |
| **键盘绑定** | 自定义快捷键、Emacs/Vim 模式 |
| **跨平台** | Linux、macOS、Windows 统一体验 |

**主要特性**：

1. **PromptSession - 会话管理**
```python
from prompt_toolkit import PromptSession

session = PromptSession()
while True:
    user_input = session.prompt(">>> ")
    print(f"You said: {user_input}")
```

2. **自动补全**
```python
from prompt_toolkit.completion import WordCompleter

completer = WordCompleter(['hello', 'world', 'exit'])
session = PromptSession(completer=completer)
```

3. **键盘绑定**
```python
from prompt_toolkit.key_binding import KeyBindings

kb = KeyBindings()

@kb.add('c-q')
def _(event):
    """Ctrl+Q 退出"""
    event.app.exit()

session = PromptSession(key_bindings=kb)
```

4. **语法高亮**
```python
from prompt_toolkit.lexers import PygmentsLexer
from pygments.lexers import PythonLexer

session = PromptSession(lexer=PygmentsLexer(PythonLexer))
```

5. **多行输入**
```python
from prompt_toolkit.key_binding import KeyBindings

kb = KeyBindings()

@kb.add('enter')
def _(event):
    """Enter 提交"""
    buffer = event.current_buffer
    if buffer.text.strip():
        buffer.validate_and_handle()

@kb.add('escape', 'enter')
def _(event):
    """Esc+Enter 换行"""
    event.current_buffer.insert_text('\n')

session = PromptSession(multiline=True, key_bindings=kb)
```

6. **底部工具栏**
```python
def get_bottom_toolbar():
    return [('class:toolbar', 'Press Ctrl+D to exit')]

session = PromptSession(bottom_toolbar=get_bottom_toolbar)
```

7. **进度条**
```python
from prompt_toolkit.shortcuts import ProgressBar

with ProgressBar() as pb:
    for i in pb(range(100)):
        time.sleep(0.01)
```

8. **样式定制**
```python
from prompt_toolkit.styles import Style

style = Style.from_dict({
    'prompt': 'ansicyan bold',
    'toolbar': 'bg:#333333 #ffffff',
})

session = PromptSession(style=style)
```

9. **Emacs/Vim 编辑模式**
```python
from prompt_toolkit.enums import EditingMode

session = PromptSession(editing_mode=EditingMode.EMACS)  # 或 VIM
```

### 问题 3
用户：基于prompt-toolkit库就可以实现一个交互式的对话框？

助手：是的，**仅用 prompt-toolkit 就可以实现一个交互式对话框**。但它只负责输入/输出交互，实际功能需要你自己实现。

**最小示例**：

```python
from prompt_toolkit import PromptSession

# 创建最简单的交互式对话框
session = PromptSession()

while True:
    try:
        user_input = session.prompt("你> ")
        if user_input.lower() in ["exit", "quit"]:
            print("再见！")
            break
        print(f"AI> 收到: {user_input}")
    except KeyboardInterrupt:
        print("\n再见！")
        break
```

运行效果：
```
你> 你好
AI> 收到: 你好
你> 今天天气
AI> 收到: 今天天气
你> exit
再见！
```

**DeepAgents CLI 的分层架构**：

```
┌─────────────────────────────────────────────────────┐
│           用户交互界面 (CLI 界面)                    │
└─────────────────────────────────────────────────────┘
                        ↑
┌─────────────────────────────────────────────────────┐
│              prompt-toolkit                         │
│  - PromptSession (输入循环)                         │

```

**职责划分**：

| 层级 | 职责 | 依赖 |
|------|------|------|
| **prompt-toolkit** | 输入/输出、键盘处理、UI 渲染 | 无 |
| **业务逻辑** | 任务执行、AI 调用、工具使用 | LangChain、LLM API |

**结论**：
- **prompt-toolkit** = 交互式**外壳**（输入框、快捷键、补全菜单）
- **你的代码** = 实际**功能**（处理输入、调用 AI、返回结果）

类比：prompt-toolkit 是餐厅的门面和服务员，你的代码是后厨的厨师。两者配合才能运营一家餐厅。

### 问题 4
用户：我想基于大模型交互，给出prompt-toolkit最简的代码

助手：## 最简大模型交互示例

```python
"""基于 prompt-toolkit 的大模型交互最简示例"""

import os
from prompt_toolkit import PromptSession
from anthropic import Anthropic

# 1. 初始化客户端和会话
client = Anthropic(api_key=os.environ.get("ANTHROPIC_API_KEY"))
session = PromptSession()

# 2. 交互循环
messages = []

while True:
    # 获取用户输入
    user_input = session.prompt("You> ")

    if user_input.lower() in ["exit", "quit"]:
        break

    # 构建消息并发送给大模型
    messages.append({"role": "user", "content": user_input})

    response = client.messages.create(
        model="claude-3-5-sonnet-20241022",
        max_tokens=1024,
        messages=messages
    )

    # 打印响应
    assistant_message = response.content[0].text
    print(f"Claude> {assistant_message}\n")

    messages.append({"role": "assistant", "content": assistant_message})
```

**运行效果**：
```
You> 什么是 Python？
Claude> Python 是一种高级编程语言...

You> 它有哪些特点？
Claude> Python 的主要特点包括：简单易学、开源、丰富的生态系统...
```

**更简洁版（无上下文记忆）**：

```python
from prompt_toolkit import PromptSession
from anthropic import Anthropic

client = Anthropic()
session = PromptSession()

while True:
    user_input = session.prompt("You> ")
    if user_input == "exit": break

    response = client.messages.create(
        model="claude-3-5-sonnet-20241022",
        max_tokens=1024,
        messages=[{"role": "user", "content": user_input}]
    )

    print(f"Claude> {response.content[0].text}\n")
```

**依赖**：
```
pip install prompt-toolkit anthropic
export ANTHROPIC_API_KEY=your_key_here
```

这就是最简实现：**输入 → 调用 LLM → 输出** 循环。
